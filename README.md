# Power BI Dashboard Projects

A collection of Microsoft Power BI (`.pbix`) business intelligence dashboards covering human resources management, monitoring & evaluation (M&E), deployment tracking, and healthcare supply chain / stock status analytics.

## Repository Structure

- **`OriginalDashboard_PBIX/`**
  - `Dashboard_HR.pbix` — Human Resources overview & workforce analytics dashboard
  - `ZenithTRI_HRMgmt.pbix` — HR Management & employee metrics dashboard
  - `DeploymentStatus_June2023.pbix` — Project deployment status tracking dashboard
  - `MnE.pbix` — Monitoring and Evaluation (M&E) performance dashboard
  - `Takeda_Dashboard.pbix` — Healthcare / supply chain operational dashboard
  - `Zenith_Dash_Samp_Part5.pbix` — Sample executive analytics dashboard
  - `Zenith_Dashboard_ALLMM.pbix` — Nationwide Myanmar operations & stock status dashboard
  - `Zenith_Dashboard_LTL.pbix` — Logistics & transport tracking dashboard
  - `Zenith_Dashboard_SCH.pbix` — Supply chain & health commodities dashboard
  - `Zenith_Dashboard_SSYCBC.pbix` — Program operations & distribution analytics dashboard
  - `Zenith_Dashboard_UNFPA.pbix` — UNFPA health commodities & inventory analytics dashboard
- **Root-level featured dashboards**
  - `DeploymentStatus_June2023.pbix`
  - `ZenithTRI_HRMgmt.pbix`

## Requirements & Usage

1. **Git LFS**: Large `.pbix` files are tracked via [Git Large File Storage (Git LFS)](https://git-lfs.com/).
   ```bash
   git lfs install
   git clone https://github.com/AungCN/PowerBI_Projects.git
   ```
2. **Microsoft Power BI Desktop**: Open any `.pbix` file using [Microsoft Power BI Desktop](https://powerbi.microsoft.com/desktop/).
